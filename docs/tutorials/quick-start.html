Quick Start

Create your first RF digital twin scene and launch the interactive editor

Step 1: Create Your Scene

Create your first RF digital twin scene with a simple example:

Basic Scene Setup

from rfdt import Scene, ObjectFactory, Server

scene = Scene()
server = Server(scene=scene, verbose=True)
server.start(host="127.0.0.1", port=8000, start_editor=False, threaded=True)

cube = ObjectFactory.create_cube(position=[0, 0, 0], name="MyCube1")
cube.add_component("Light")
scene.add_object(cube)

for i in range(2):
    input("Press Enter to continue...")

Save this code to a file, for example: demo.py

Run the server

python demo.py

The server will start on http://127.0.0.1:8000

Step 2: Launch Editor

Once the server is running, launch the interactive editor:

Access the Editor

Click the Launch button in the top-right corner of this page to enter the interactive 3D editor.

The editor provides a real-time visual interface for building and manipulating your RF digital twin scenes.

Step 3: Add a Radar

Add a radar to your scene using the Hierarchy panel:

1

Open Hierarchy Panel

In the left sidebar, locate the Hierarchy panel.

2

Add Radar Object

Click the + button in the Hierarchy panel and select Radar from the menu.

Step 4: Position the Radar

Adjust the radar's position to face the cube:

Use the Viewport Panel

In the center Viewport panel, use the transform tools to adjust the radar's position and rotation so it faces toward the cube.

Step 5: Render the Scene

Perform the RF simulation to see the radar results:

1

Select the Radar

Click on the radar object in either the Hierarchy panel or the Viewport to select it.

2

Click Render

In the right-side Properties panel, locate and click the Render button to start the simulation.

View Results

After rendering completes, the simulation results will be displayed in the Results panel at the bottom of the editor.

Understanding the Results

The Results panel displays six visualization plots that help you understand the radar simulation:

1

Radar View Rendering

A virtual render from the radar's perspective, showing the scene geometry as the radar "sees" it.

2-3

FMCW Signal (Real & Imaginary)

The real and imaginary components of the basic FMCW (Frequency-Modulated Continuous Wave) radar signal, representing the raw received signal in the time domain.

4-5

Signal Gradients

The computed gradients of the signal components, useful for optimization and inverse problems in RF digital twin applications.

6

Frequency Domain Spectrum

The frequency domain representation of the actual received signal, showing the spectral content and target responses.

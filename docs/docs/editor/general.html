Interface Overview

The RFDT Editor is a web-based visual interface that provides real-time visualization and interactive control of your RF digital twin simulations. It consists of 9 main panels, each designed for specific tasks in your workflow.

Editor Panels

Viewport

Main 3D viewport for visualizing your scene, objects, and simulation results

Learn more →

Hierarchy

Tree view of all scene objects with selection and organization tools

Learn more →

Properties

Edit object components and properties with real-time synchronization

Getting Started

The RFDT Editor automatically opens when you start the PyRFDT server with start_editor=True. You can also access it manually by navigating to localhost:8080 in your browser.

PyRFDT Overview →Launch Web Editor →
